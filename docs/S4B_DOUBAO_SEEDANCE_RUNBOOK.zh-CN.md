# 豆包 / Seedance 写实数字人素材生产 Runbook

本 Runbook 用于在豆包、即梦或火山方舟中，使用 Seedream 生成角色参考图，再使用
Seedance 2.0 生成 S4b 数字人视频素材。界面名称可能随产品版本变化；以当前页面显示的
模型、时长、清晰度和消耗为准。

项目状态机、素材包格式和实现细节另见 [S4B.md](./S4B.md) 与
[ROADMAP.zh-CN.md](./ROADMAP.zh-CN.md)。

## 目标产物

主流程产出：

- `face-neutral.png`：正脸近照，只负责锁定身份。
- `anchor-neutral.png`：闭嘴、中性、固定构图的竖版锚点图。
- `speaking-selected.mp4`：克制、可循环的通用说话素材。

如果要直接组成完整 S4b 素材包，还需要：

- `idle-selected.mp4`
- `listening-selected.mp4`
- `thinking-selected.mp4`

不要用不同角色、不同服装或不同构图的素材拼成一个包。

## Seedance 的关键生产规则

1. 固定使用两张人物参考图：`图片1 = 正脸近照`，`图片2 = 竖版锚点图`。
2. 不要制作多视角人物九宫格或正侧背拼图。模型可能把它理解成多人，反而增加身份漂移。
3. Prompt 中先定义图片与人物的绑定关系，再始终使用同一个称呼“数字人”。
4. 使用“开始、随后、接着、结束前”的事件顺序，不依赖精确到秒的动作控制。
5. 每个视频只使用一个固定机位、一个连续镜头、少量低幅度动作。
6. 明确排除字幕、文字、Logo 和水印；即使如此仍需人工检查，不能视为百分之百保证。
7. 如果界面提供首帧和尾帧输入，首尾都使用完全相同的 `anchor-neutral.png`。

这些规则来自官方的
[Seedance 2.0 Prompt 指南](https://www.volcengine.com/docs/82379/2222480?lang=zh)和
[可信素材库指南](https://www.volcengine.com/docs/82379/2315856?lang=zh)。

## 前置条件

- 可访问豆包、即梦或[火山方舟体验中心](https://console.volcengine.com/ark/region:ark+cn-beijing/experience/vision?modelId=doubao-seedance-2-0-260128)。
- 图片阶段可使用 Seedream；视频阶段使用 Seedance 2.0。
- 使用真人形象前，已取得本人身份、肖像和素材授权。
- 使用第三方服装、品牌、场景或作品时，已确认相应使用权。
- 本机有足够空间保存原始候选、入选文件和 Prompt 记录。

成本、活动套餐和赠送额度会变化。每次批量生成前，以产品当前页面和
[官方活动页](https://www.volcengine.com/activity/seedance2)显示为准。

## 1. 建立项目与固定变量

建议项目名：

```text
persona-s4b-seedance-v1
```

先填写以下变量。后续 Prompt 原样复用，不要频繁替换同义词。

```text
CHARACTER = [年龄、性别呈现、脸型、肤色、发型、发色、稳定且不侵权的辨识特征]
WARDROBE = [上衣、下装、鞋、配饰；颜色和材质写清楚]
BACKGROUND = [固定、简洁、低对比度的室内或纯色背景]
FRAMING = 居中三分之四身竖版构图，完整显示头部、前臂和双手
LIGHTING = 正面偏左的柔和均匀棚拍光，无变化阴影
```

背景避开屏幕、窗帘、树叶、人群、镜子、强反光、文字和其他容易漂移的元素。

## 2. 生成身份近照 `face-neutral.png`

### 2.1 操作

1. 打开图片生成或图片创作，选择当前可用的 Seedream 模型。
2. 画幅选择竖版；生成 2–4 张即可。
3. 使用下面的“身份近照 Prompt”。
4. 只保留一张正面、中性、清晰、没有遮挡的图片。
5. 下载并命名为 `face-neutral.png`。

### 2.2 身份近照 Prompt

```text
生成一张写实数字人的正面身份参考近照。

人物：[CHARACTER]。

竖版正面构图，从肩部以上取景，人物直视镜头，脸部约占画面高度的三分之二。
头部端正，五官左右清晰可见，头发不遮挡眼睛和脸部轮廓。表情中性友好，双眼自然睁开，
嘴唇完全闭合，不露牙齿。真实自然的皮肤纹理、毛发和面部比例。

使用柔和均匀的正面棚拍光和简洁低对比度纯色背景。单人、单张图片、摄影写实风格。

不要侧脸，不要俯拍或仰拍，不要夸张表情，不要张嘴，不要露齿，不要手部遮脸，
不要眼镜反光，不要帽子，不要文字、字幕、Logo、水印、边框或多视角拼图。
```

### 2.3 身份近照修正 Prompt

编辑已生成的近照时使用：

```text
严格保留当前人物的身份、脸型、五官比例、肤色、发型、发色、光线和背景。
只修正这个问题：[ISSUE]。

修正后仍为正面肩部以上身份近照，脸部清晰完整，头部端正，表情中性，嘴唇完全闭合，
不露牙齿。不要重新设计人物，不要改变年龄感、妆容、发型、摄影风格或构图。
```

### 2.4 验收

- 正脸、清晰、无遮挡，脸部约占画面三分之二。
- 嘴完全闭合，不露齿。
- 没有异常眼睛、牙齿、耳朵或脸部不对称。
- 没有文字、Logo、水印或多视角拼图。

## 3. 生成竖版锚点图 `anchor-neutral.png`

### 3.1 操作

1. 新建图片编辑或参考图生成任务。
2. 上传 `face-neutral.png`，固定作为 `图片1`。
3. 画幅选择 **9:16**。
4. 使用下面的“锚点图 Prompt”，生成 2–4 张。
5. 只选择一张身份、手部、构图和背景都稳定的图片。
6. 下载并命名为 `anchor-neutral.png`。

### 3.2 锚点图 Prompt

```text
将图片1中的人物定义为“数字人”。生成一张该数字人的写实竖版制作锚点图。

数字人的面部身份、脸型、五官比例、肤色、发型和发色严格参考图片1。
服装：[WARDROBE]。
背景：[BACKGROUND]。

竖屏9:16，居中三分之四身构图，平视固定机位，自然50毫米人像透视。完整显示头部、
肩膀、躯干、前臂和双手，画面四周留有安全边距。人物自然站立，肩膀放松，双臂和双手
自然放置，视线略高于镜头，表情中性友好，嘴唇完全闭合，不露牙齿。

光线：[LIGHTING]。摄影写实，真实自然的皮肤、头发、手指、服装纹理和人体比例。
背景完全静止，适合作为后续数字人视频的统一首帧和身份参考。

只生成一个人物和一张图片。不要改变图片1的人物身份，不要裁掉头部或双手，
不要多余手指、异常手部、张嘴、露齿、道具、其他人物、文字、字幕、Logo、水印、
边框、夸张透视或多视角拼图。
```

### 3.3 通用锚点图修正 Prompt

编辑锚点图时，把待编辑的锚点图作为 `图片1`：

```text
严格编辑图片1。保留已经正确的人物身份、五官、发型、服装、背景、灯光、机位、构图、
姿势和身体比例，所有已接受元素保持不变。

只修正这个问题：[ISSUE]。修正区域需要与原图自然融合。人物嘴唇仍然完全闭合，不露牙齿；
头部和双手仍完整位于画面内。不要重画或重新设计其他区域，不要改变整体风格。
```

### 3.4 常用 `ISSUE` 示例

```text
右手多出一根手指；只修正右手为自然的五指结构
嘴唇有缝隙并露出牙齿；只修正为自然闭嘴
头顶距离画面边缘过近；只增加少量顶部安全边距
人物脸部与身份近照不一致；只恢复身份近照中的脸型和五官比例
背景出现模糊文字；只清除文字并恢复原有纯净背景
```

## 4. 准备 Seedance 视频任务

### 4.1 固定参考图顺序

在每一个视频任务中保持：

```text
图片1 = face-neutral.png
图片2 = anchor-neutral.png
```

不要在不同候选中互换顺序。Prompt 开头始终使用：

```text
将图片1中人物的面部身份和图片2中人物的妆造、构图统一定义为“数字人”。
数字人的面部特征严格参考图片1，发型、服装、身体比例、背景和构图严格参考图片2。
```

### 4.2 推荐设置

- 模型：方向探索可选界面中的 Seedance 2.0 Fast；入选候选使用 Seedance 2.0。
- 画幅：9:16。
- 时长：优先 6 秒；没有 6 秒时选择最接近的可用时长。
- 清晰度：初稿用较低成本档，最终候选再用 1080p 或当前最高合适档位。
- 声音：如果界面提供音频开关，关闭音频生成。
- 镜头：固定机位、单镜头，不使用运镜模板。

### 4.3 首尾帧的两种路径

**路径 A：界面提供首帧和尾帧。**

1. 首帧上传 `anchor-neutral.png`。
2. 尾帧再次上传完全相同的 `anchor-neutral.png`。
3. 如果界面还能添加人物参考图，再加入 `face-neutral.png` 锁定脸部。

**路径 B：界面只有多模态参考图。**

上传 `图片1` 和 `图片2`，使用本文 Prompt 中的“结束前回到图片2姿势”约束。该路径不能保证
数学意义上的同帧闭环，必须以实际循环播放结果为准。

## 5. Speaking 视频

### 5.1 Speaking Prompt

```text
将图片1中人物的面部身份和图片2中人物的妆造、构图统一定义为“数字人”。
数字人的面部特征严格参考图片1，发型、服装、身体比例、背景和构图严格参考图片2。

生成一段竖屏9:16、固定机位、单一连续镜头的写实数字人通用说话循环。

画面开始时，数字人处于图片2的原始中性姿势，嘴唇完全闭合，视线略高于镜头。
随后，数字人像在进行简短而平静的日常对话：无声说一小句，使用缓慢、克制、自然变化的
口型；配合两次幅度很小的自然点头和极轻微的上半身交流动作。双手始终保持在原有轮廓内，
不遮挡脸部。
接着，嘴部短暂停顿并自然闭合。
画面结束前，数字人平滑回到图片2中的闭嘴、中性姿势，视线、肩膀、双手、头发轮廓、
人物大小、灯光和背景都与开始时一致，并短暂保持静止，便于循环播放。

动作适合小尺寸桌面窗口观看，幅度小、速度慢、自然稳定。全程保持同一张脸、同一套服装、
同一身体比例和同一背景。嘴型是通用说话动作，不对应可辨认的具体台词。

不要生成可听见的对白、音乐或环境声。不要快速咀嚼式嘴动、夸张元音、持续张嘴、舌头特写、
大幅手势、身体转身、运镜、推拉、切镜、闪烁、变形、换脸、背景变化、新物体、文字、字幕、
Logo或水印。
```

### 5.2 首轮候选

1. 先生成 3 条，分别命名为 `speaking-c01`、`c02`、`c03`。
2. 只要有一条动作方向正确，再补到最多 6 条。
3. 如果三条都有同一问题，先改 Prompt，不要继续盲目抽卡。

## 6. 视频修正 Prompt 库

修正时保留原 Prompt，只在末尾追加一个修正块。一次只解决一个主要问题。

### 6.1 通用单问题修正 Prompt

```text
本次只做单项修正：保持所有已经正确的人物身份、五官、发型、服装、构图、机位、灯光、
背景和已接受动作不变。只修正 [ISSUE]。将相关动作幅度降低约一半，并让过渡更加缓慢连续。
不要添加新动作、新物体、新镜头或新视觉风格。
```

### 6.2 身份漂移修正 Prompt

```text
本次只修正身份漂移。数字人的脸部身份以图片1的正脸近照为最高优先级，脸型、眼睛、鼻子、
嘴唇、下颌线、肤色、年龄感和发型在每一帧都保持一致；妆造和身体比例参考图片2。
不要平均融合两张脸，不要改变妆容，不要在张嘴或转头时换脸。其他动作保持不变。
```

### 6.3 嘴部动作过快修正 Prompt

```text
本次只修正嘴部动画。保持人物身份、机位、构图、姿势、服装、灯光、背景和已接受的身体动作
不变。口型速度降低，幅度缩小，减少下颌开合距离；使用缓慢、克制、自然变化的对话口型，
短语之间出现短暂自然闭唇。不要快速咀嚼、重复机械开合、夸张元音、持续张嘴或嘴部冻结。
```

### 6.4 首帧没有闭嘴修正 Prompt

```text
本次只修正视频开头。第一帧必须严格保持图片2中的中性表情，嘴唇自然且完全闭合，不露牙齿，
下颌放松。先短暂保持闭嘴静止，再平滑开始说话动作。人物身份和其他动作保持不变。
```

### 6.5 循环接缝修正 Prompt

```text
本次只修正循环接缝。动作结束后更早、更缓慢地回到图片2的原始中性姿势。最终的闭嘴状态、
视线、头部角度、肩膀、双手、头发轮廓、人物大小、亮度和背景必须与开头一致；结束前短暂
保持完全静止。不要使用淡入淡出、转场、运镜或切镜来掩盖接缝。
```

### 6.6 镜头或背景漂移修正 Prompt

```text
本次只修正镜头和背景漂移。摄像机完全锁定，焦距、人物大小、裁切和透视全程不变。
背景像一张静止照片一样保持完全一致，不得呼吸、扭曲、闪烁或出现新物体。人物动作保持不变。
```

### 6.7 手部异常修正 Prompt

```text
本次只修正手部。双手始终保持自然五指结构和图片2中的原始位置，动作幅度极小，不交叉、
不遮脸、不穿过身体、不增加或丢失手指。人物身份、面部和其他已接受动作保持不变。
```

### 6.8 字幕、文字、Logo 或水印修正 Prompt

```text
本次只修正画面中的生成文字。全程保持干净画面，不生成任何文字、汉字、英文字母、数字、
字幕、对白文本、标题、Logo、边框或非平台强制水印。保持人物、动作、机位、构图和背景不变。
```

平台依法或依规则添加的来源标记不应通过裁切、遮挡或其他方式规避。

## 8. 候选命名与筛选

### 8.1 命名

```text
speaking-c01-fast-p1.mp4
speaking-c02-fast-p1.mp4
speaking-c03-standard-p2.mp4
```

- `c01`：候选编号。
- `fast` / `standard`：实际使用的模型档位。
- `p1`：Prompt 版本。

修正后增加 Prompt 版本，不覆盖原候选。

### 8.2 评分

每项 0–2 分，总分至少 8 分才可入选：

| 项目 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 身份稳定 | 明显换脸 | 轻微漂移 | 全程稳定 |
| 循环接缝 | 明显跳变 | 轻微接缝 | 肉眼无缝 |
| 状态动作 | 抽搐或过快 | 尚可 | 自然克制 |
| 解剖与服装 | 明显错误 | 小瑕疵 | 稳定自然 |
| 构图与背景 | 漂移或裁切 | 轻微变化 | 完全固定 |

以下任一情况直接淘汰：

- 第 0 帧没有闭嘴。
- 切镜、推拉、构图变化或背景闪烁。
- 人脸、牙齿、下颌、手指或衣服明显变形。
- 嘴部突然冻结、持续张开或动作明显过快。
- 出现模型生成的字幕、文字或 Logo。
- 首尾存在明显姿态、亮度或人物尺寸跳变。

## 9. 下载、静音与交付

### 9.1 下载命名

下载评分最高的候选，并命名为：

```text
face-neutral.png
anchor-neutral.png
idle-selected.mp4
listening-selected.mp4
thinking-selected.mp4
speaking-selected.mp4
```

### 9.2 交付前检查

- 四条视频来自同一身份、同一套服装、同一机位和同一背景。
- 画幅均为 9:16，分辨率、帧率和编码尽量一致。
- 四条视频第 0 帧均闭嘴；非 speaking 状态全程闭嘴。
- 视频没有可听见的对白、音乐或环境音轨。
- 没有模型生成的字幕、文字或 Logo。
- 循环播放 10 次，肉眼没有明显跳变。

即使 Prompt 写了“无声”，也不能假设下载文件没有音轨。进入 S4b 前应实际检查并移除音频。
具体素材包命名和安装按 [S4B.md](./S4B.md) 执行。

### 9.3 Mac 最小静音处理

Mac 尚未安装 FFmpeg 时，只需安装一次：

```bash
brew install ffmpeg
```

对最终 speaking 文件移除音轨，同时不重复压缩视频：

```bash
ffmpeg -i speaking-selected.mp4 -map 0:v:0 -c:v copy -an speaking.mp4
```

检查输出中是否只剩视频流：

```bash
ffprobe -v error -show_entries stream=codec_type -of default=noprint_wrappers=1 speaking.mp4
```

正确结果只应显示 `codec_type=video`。其余三个状态用相同方法处理，并分别输出为
`idle.mp4`、`listening.mp4` 和 `thinking.mp4`。

## 10. 回退与止损

- **同一问题连续出现 3 次：**停止增加候选，改用对应的单问题修正 Prompt。
- **身份仍漂移：**重新制作更清晰的正脸近照，并把身份绑定句放在 Prompt 第一段。
- **动作一直过大：**删除所有非必要动作，每条只保留一个主动作和一个眨眼。
- **循环始终失败：**优先使用支持相同首尾帧的入口；仍失败时选择接缝最小的候选，在交付阶段
  做轻量裁剪或交叉淡化，不继续无限抽卡。
- **字幕反复出现：**换用不含文字的纯净背景，关闭可能触发对白的音频设置，重新生成。
- **预算达到预设上限：**保留最佳候选并停止生成；不要为了小瑕疵无上限追加消耗。
- **需要逐音素口型同步：**本 Runbook 的 speaking 是通用幅度驱动素材，不承担精确台词口型；
  改用专门的音频驱动或口型同步链路。

所有原候选都保留，回退时切回上一个合格版本，不覆盖或删除已通过验收的文件。
